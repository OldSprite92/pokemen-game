# 宝可梦语言研究所：拼音与英语玩法设计

> 实现状态（2026-09-29）：完整课程已经落地，包含 24 位自创伙伴、18 个正式属性、6 题短局、跨天熟练度、每日奖励、学习图鉴和家长概览。根据试玩反馈，所有属性英语学习与答题界面均不使用属性图标，避免依靠图形猜答案。

## 1. 设计结论

在首页新增一个相对独立的入口：**“🧪 语言研究所”**。

它不强行接入地图战斗的操作循环，而是借用现有的宝可梦图片、图鉴、精灵球、贴纸和训练师身份，形成一条轻量支线：

> 选择研究任务 → 认识本轮伙伴 → 完成拼音/英语小游戏 → 温柔纠错与复习 → 点亮图鉴学习印章 → 领取研究奖励

单次目标时长为 **3～5 分钟**，每局 **6 道题**，最多引入 **2 个新宝可梦或新单词**。孩子随时退出不受惩罚，答错也不会失去已有奖励。

这个模块的定位不是“披着宝可梦皮的考试”，而是“孩子已经是宝可梦专家，现在帮助研究所翻译资料”。熟悉的宝可梦是学习新内容的支架，而不是答题奖励本身。

## 2. 目标玩家与设计支柱

- 核心玩家：小学一年级、熟悉绝大多数宝可梦外形与中文名，但正在学习拼音和基础英语。
- 陪伴者：家长可以选择本周学习内容、查看薄弱项，但不需要全程陪玩。
- 使用场景：每天一次短练习；愿意时可以继续自由练习，但不会通过无限刷题获得大量战斗资源。

| 设计支柱 | 含义 | 对应系统 |
|---|---|---|
| 熟悉感带动学习 | 用已知的宝可梦形象和名字承载陌生的拼音、英文 | 宝可梦卡片、图鉴学习印章、研究所叙事 |
| 小步成功、答错无惩罚 | 题量短、选择少、立即提示，不用红叉和失败结算制造压力 | 6 题短局、分级提示、自动降低难度 |
| 真正记住，而非蒙对 | 同一知识点跨天、换版式、换题型复现 | 双维度熟练度、间隔复习、首答记录 |
| 奖励努力，也奖励掌握 | 完成就有进度；真正掌握则获得收藏展示 | 每日研究章、图鉴金框、属性徽章 |

## 3. 核心循环与一局流程

### 核心循环

**选任务 → 看/听 → 配对或选择 → 获得即时反馈 → 复习错题 → 点亮收藏 → 下次复习**

### 一局 3～5 分钟

1. **接任务（10 秒）**  
   博士给出一句短目标，例如“帮我找出 3 只伙伴的名字”。孩子选择“拼音任务”或“属性英语任务”。
2. **认识伙伴（20～30 秒）**  
   展示本轮 2～3 张卡片。点击图片会朗读中文名、逐字拼音；属性卡会朗读中文和英文。
3. **练习（4 题）**  
   以本轮知识为主，穿插一个上次答错的项目。
4. **研究所挑战（2 题）**  
   换一种排列或问法，确认孩子不是靠位置记答案。
5. **结算（15 秒）**  
   先展示“今天帮助了哪些宝可梦”，再展示研究章、图鉴印章或游戏道具。

## 4. 玩法设计

### 4.1 拼音连连看（首发核心玩法）

屏幕上方放 3 张宝可梦图片，下方放 3 个完整拼音。孩子先点一个拼音，再点一张图片，系统画出连线。

- 首发采用“点两端完成连线”，不要求持续拖拽，避免触屏手势失败被误认为答错。
- 拼音按汉字分组显示，例如：`pí  kǎ  qiū`，声调符号必须保留。
- 初级可在图片下显示中文名；进阶隐藏中文名，只保留图片和语音按钮。
- 每次重排卡片位置，防止只记住布局。
- 首次答错后不出现刺眼红叉，播放一句“再听一次”，朗读名字并排除一个错误选项。
- 同一道错题隔 2 题再次出现，并在下一次游戏优先复习。

### 4.2 拼音积木（第二阶段）

给出一张图片，把名字拆成 2～4 个拼音块，让孩子按顺序排列。

- 初级：完整音节块，例如 `pí / kǎ / qiū`。
- 中级：声母、韵母与声调组合，例如 `p + í → pí`。
- 高级：听语音后选择正确声调，或找出名字里的指定声母/韵母。
- 不建议首版加入键盘输入；一年级孩子的输入与拼音知识容易混在一起，影响判断学习效果。

### 4.3 属性英语门（首发核心玩法）

显示一只伙伴，让孩子从纯文字英文属性卡中选择正确单词。

- 第一次见到单词时显示“火属性 / Fire”并提供可点击朗读。
- 正式答题只显示英文单词，不显示属性图标，也不在无障碍名称中附带中文答案。
- 初级每题 2 个选项，稳定后增加到 3 个，最高不超过 4 个。
- 双属性题必须等两个单属性都熟悉后再开放，先选一个、再选另一个。
- 英文大小写固定采用标题式：`Fire`、`Water`，避免同一阶段混用多种写法。

### 4.4 听音寻宝与综合挑战（后续玩法）

- **听音寻宝**：只播放名字或属性英文，从 3 张卡中找目标。
- **反向属性题**：给出 `Water`，选择水属性图标或对应宝可梦。
- **研究所 Boss**：连续完成“图片找拼音 + 英文找属性”两步，完成一份宝可梦研究报告。
- 语音朗读识别可作为远期可选玩法，但不能作为领取奖励的必要条件；儿童语音识别失败会造成错误挫败。

## 5. 学习内容与难度阶梯

### 拼音阶梯

| 阶段 | 呈现 | 选项数 | 通过条件 |
|---|---|---:|---|
| P0 认识 | 图片 + 中文名 + 分词拼音 + 语音 | 无考试 | 点听并看完 2～3 张卡 |
| P1 配对 | 图片 + 完整带调拼音 | 2～3 | 单题首答正确 |
| P2 排序 | 图片 + 完整音节块 | 2～4 块 | 顺序正确 |
| P3 分解 | 图片 + 声母/韵母/声调 | 2～3 选项 | 完成目标音节 |
| P4 听辨 | 语音 + 图片/拼音选项 | 3 | 不看中文首答正确 |

拼音数据必须人工校对，尤其注意多音字、轻声、`ü` 和声调落点。宝可梦名称可能包含一年级课本外的生字，因此学习目标应是“读准音节”，不要同时要求孩子认识所有汉字。

### 英语属性阶梯

首版不要一次展示全部属性。建议按 4 → 8 → 14 → 18 个逐步扩展：

| 阶段 | 新增单词 | 设计理由 |
|---|---|---|
| E1 | Fire, Water, Grass, Ice | 含义具体、图标差异大 |
| E2 | Electric, Rock, Ground, Flying | 与常见宝可梦特征关联强 |
| E3 | Bug, Poison, Ghost, Dragon, Steel, Fairy | 继续使用明显视觉语义 |
| E4 | Normal, Fighting, Psychic, Dark | 较抽象或拼写更难，最后加入 |

正式属性英文应使用官方通行的 18 种：Normal、Fire、Water、Electric、Grass、Ice、Fighting、Poison、Ground、Flying、Psychic、Bug、Rock、Ghost、Dragon、Dark、Steel、Fairy。

当前游戏另有 `light` 自创属性，必须明确标注为“本游戏自创属性 / Light”，不能混进“官方 18 种属性”课程。现有界面中 `flying` 显示为“风”、`psychic` 显示为“光”，用于教学前也应调整为“飞行”和“超能力”，否则中文概念与英文会错位。

## 6. 熟练度与出题规则

拼音和属性英语分开记录熟练度，不能因为认识了拼音就认为已经学会英文。

| 状态 | 规则 | 图鉴显示 |
|---|---|---|
| 未学习 | 从未出现 | 灰色空印章 |
| 学习中 | 已练习，但尚未跨天稳定 | 彩色半印章 |
| 熟悉 | 在至少 2 局中首答正确 2 次 | 彩色完整印章 |
| 已掌握 | 至少 3 个不同日期累计首答正确 4 次，且提示不超过 1 次 | 金色印章 |

每局 6 题的推荐组成：

- 3 题来自薄弱或到期复习项（50%）。
- 2 题来自新内容（33%，最多 2 个新项目）。
- 1 题来自已掌握内容（17%，用于防遗忘）。

动态难度目标是让首答正确率保持在 **75%～90%**：

- 最近 6 题低于 70%：选项减 1，恢复中文/图标提示，暂停加入新内容。
- 最近 12 题高于 90%：隐藏一层提示或增加 1 个选项。
- 连续答错 2 次：直接进入“并排教学”，展示正确答案并朗读，不再要求反复猜。
- 只有首答结果计入熟练度；提示后的正确答案仍然给予正向动画，但不虚增掌握数据。

## 7. 奖励设计

奖励分为两条：**完成奖励认可努力，掌握奖励认可长期记忆**。

| 触发条件 | 奖励 | 限制与目的 |
|---|---|---|
| 每次正确配对 | 动画、声音、研究进度条 +1 格 | 只做即时反馈，不发可刷资源 |
| 完成 6 题 | 展示本局研究报告 | 无论正确率，保证孩子愿意完成 |
| 每天首次完成一局 | 研究章 ×1、普通精灵球 ×1 | 每日最多一次，避免刷最简单题 |
| 累积 5 枚研究章 | 研究员贴纸 ×1、高级球 ×1 | 消耗 5 枚研究章，形成完整循环 |
| 某只宝可梦拼音与英文均“已掌握” | 图鉴学习金框、专属庆祝动画 | 永久收藏，不增加战斗强度 |
| 每掌握一个英语阶段 | 属性研究徽章、训练师称号/主页装饰 | 清晰的长期目标 |
| 全部 18 属性掌握 | “属性词大师”纪念徽章与限定贴纸 | 一次性毕业奖励 |

### 奖励经济闭环

| 资源 | 来源 | 消耗/出口 | 目标流量 |
|---|---|---|---|
| 研究章 | 每日首次完成 +1 | 5 枚兑换研究员礼包 | 每周约完成一次兑换，不要求连续签到 |
| 普通精灵球 | 每日首次学习 +1 | 现有捕获系统 | 每周最多 +7，不因反复刷题膨胀 |
| 高级球 | 每 5 枚研究章 +1 | 现有捕获系统 | 每 5 个学习日 +1 |
| 贴纸/徽章/金框 | 阶段或掌握成就 | 永久收藏展示，不作为货币 | 只记录里程碑 |

不建议首版给宝可梦战斗经验或大量钻石。否则最优策略会变成反复刷最简单的题来练级，学习目标和冒险平衡都会被破坏。

## 8. 与现有游戏的连接

- 首页新增“🧪 语言研究所”，与“开始冒险”“宝可梦图鉴”并列，但不阻塞主线。
- 图鉴卡片增加两个小印章：`拼音`、`English`；点开可听读名字和属性。
- 地图首次遇见的新伙伴可加入研究所待学习列表；研究所的掌握结果反过来点亮图鉴金框。
- 每日任务可以显示“今天已完成研究”，但学习不应成为进入地图、战斗或捕获的强制门槛。
- 研究奖励沿用现有普通球、高级球、贴纸体系，不再新增一套复杂商店货币。
- 家长页只展示三件事：本周练了什么、哪些已经掌握、哪些需要复习；不显示班级排名或负面分数。

## 9. 首版内容预算（推荐 MVP）

第一版只证明两个问题：孩子愿不愿意主动玩，以及能不能真的记住。

| 内容 | 首版范围 |
|---|---|
| 宝可梦/伙伴 | 24 只，优先选孩子最熟悉、名字 2～4 个音节且发音无争议的对象 |
| 英语属性 | 18 个正式属性，按 E1～E4 四组渐进学习 |
| 题型 | 拼音连连看、属性英语门 |
| 每局 | 6 题，3～5 分钟，最多 2 个新项目 |
| 反馈 | 中文与英文语音、连线动画、温柔纠错 |
| 进度 | 拼音/英语独立熟练度、错题回访、跨天复习 |
| 奖励 | 研究章、普通球、高级球、研究贴纸、图鉴学习金框 |
| 家长能力 | 选择本周卡组、查看薄弱项、重置某项熟练度 |

首版不做：语音识别、自由拼写、在线题库、排行榜、复杂剧情、全部宝可梦全量录入。验证成功后再增加拼音积木、双属性题、课本词汇包。

## 10. 主要风险与防护

| 风险 | 表现 | 防护 |
|---|---|---|
| 靠位置或图片蒙对 | 同一布局正确，换布局就不会 | 每题重排；首答才计熟练度；加入反向题 |
| 宝可梦知识压过学习 | 只看图，不看拼音/英文 | 研究所挑战隐藏中文；跨题型复现 |
| 拼音内容与课本冲突 | 多音字、声调或 `ü` 标注不一致 | 所有名称人工校对，不依赖自动转拼音 |
| 英语一次太多 | 18 个按钮造成猜测和放弃 | 每阶段新增 4～6 个，单题最多 4 个选项 |
| 奖励喧宾夺主 | 重复刷简单题拿球 | 战斗资源每日封顶；主要奖励改为图鉴收藏 |
| 错误反馈造成挫败 | 连错后退出或拒绝再玩 | 无扣分；两次错误后直接教学；降低下一题难度 |
| 语音识别误判 | 孩子读对却被判错 | 语音识别仅作可选反馈，不影响奖励与熟练度 |
| 属性概念教错 | 自创属性、中文标签与官方英文混淆 | 教学词库与战斗显示解耦并人工审核映射 |
| 内容版权 | 公开发布时使用未经授权图片/音频 | 家庭自用可使用本地素材；公开分发前改用有权使用的素材或自创伙伴 |

## 11. 试玩假设与成功指标

| 系统 | 假设 | 首轮成功指标 |
|---|---|---|
| 6 题短局 | 孩子能独立完成且愿意再来一局 | 80% 以上的开局能完成；中位时长 3～5 分钟 |
| 拼音配对 | 熟悉图片能帮助建立名字与拼音的连接 | 第 3 个学习日，无提示旧题首答正确率 ≥75% |
| 属性英语 | 图标和宝可梦能帮助记住英文类型词 | 一周后从首批 4 词中正确识别至少 3 个 |
| 温柔纠错 | 答错不会导致放弃 | 答错后继续完成下一题的比例 ≥90% |
| 跨天熟练度 | 系统记录的是记忆而非单局短时记忆 | “已掌握”项目在 7 天后复测正确率 ≥70% |
| 奖励 | 奖励能带来期待但不诱导刷题 | 每日平均 1～2 局；多数游戏不会只重复最低难度 |
| 家长页 | 家长能快速知道该复习什么 | 家长 30 秒内能指出 1～3 个薄弱项目 |

## 12. 实现交接要点

### 内容数据

每张学习卡至少需要：宝可梦唯一 ID、中文名、逐字带调拼音、音节拆分、图片、中文属性、英文属性、中文语音、英文语音、内容来源/授权标记。

### 核心状态

- 每位训练师独立保存学习记录。
- 每个宝可梦分别保存拼音熟练度和属性英语熟练度。
- 记录首答结果、提示次数、练习日期、下次复习日期和连续错误次数。
- 研究章、每日奖励领取日期、阶段徽章必须按训练师隔离。

### 页面与状态流转

`研究所首页 → 模式/卡组选择 → 认识卡片 → 6 题答题 → 研究报告 → 奖励 → 返回研究所或再来一局`

### 首版必须可调参数

- 每局题数：默认 6。
- 新项目上限：默认 2。
- 选项数：2～4。
- 题目组成：薄弱 50% / 新内容 33% / 已掌握 17%。
- 难度升降阈值：70% / 90%。
- 跨天掌握要求：3 天、首答正确 4 次。
- 每日奖励上限：1 次。
- 研究章兑换门槛：5 枚。

这些数值应配置化，第一轮由 5～7 天家庭试玩数据决定是否调整，而不是直接扩充大量内容。
