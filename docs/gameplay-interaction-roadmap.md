# 宝可梦大冒险：玩法与互动迭代路线图

> 本文补充 `gameplay-optimization-spec.md`：前者定义儿童友好的基础体验，本文聚焦下一轮可实施的玩法闭环与亲子互动。战斗细则见 `battle-system-design.md`。

## 1. 定位与设计支柱

目标玩家仍是 7 岁孩子与陪玩的家长，但玩法深度按有丰富游戏经验的 10 岁玩家设计。规则通过图标、短句和逐步解锁呈现，不以降低策略空间为代价。

1. **这是“我的伙伴”的冒险。** 自创的名字、性格、技能和选择必须在事件、战斗、奖励中持续被看见。
2. **每 5–8 分钟完成一个可讲述的小故事。** 玩家打开游戏就知道目标，过程中有选择，结束时有清晰成果。
3. **简单操作承载真实选择。** 孩子点击与决定；家长可读旁白、扮演 NPC，但不替代孩子做主。

任何新功能至少服务其中一条；不服务时不进入当前版本。

## 2. 核心循环

```text
看见今日目标
  → 在地图选择路线或回应事件
  → 战斗、交朋友或收集线索
  → 获得伙伴/地图的可见变化
  → 解锁下一步目标或写入冒险相册
```

| 循环层级 | 时长 | 玩家行为 | 预期感受 |
| --- | --- | --- | --- |
| 即时 | 10–30 秒 | 点路线、做二选一、选择技能 | “这是我决定的” |
| 小局 | 5–8 分钟 | 完成一个大陆小目标 | “我完成了一件事” |
| 长线 | 3–5 次冒险 | 收集线索、伙伴、贴纸或徽章 | “我的世界在长大” |

## 3. 地图从随机格子变成小故事

每次冒险提供 1 个大陆目标、1–2 个可选支线和 2–3 个短事件。事件控制在两句文字、两个大按钮；选择应改变本次冒险的路径、奖励或 Boss 信息，而不是只换一句文案。

| 场景 | 选择 | 结果 | 服务支柱 |
| --- | --- | --- | --- |
| 草丛传来哭声 | 帮忙找 / 继续前进 | 线索或更短路线 | 我的伙伴、可讲述故事 |
| 发光的岔路 | 走亮路 / 走近路 | 宝箱更多或更早遭遇伙伴 | 真实选择 |
| 野生伙伴挡路 | 对战 / 送它喜欢的东西 | 战斗奖励或友好度/捕捉机会 | 我的伙伴 |
| 守护者的传闻 | 调查 / 直接挑战 | 获得 Boss 机制提示或更快开战 | 真实选择 |

### 大陆垂直切片

先把一个大陆做完整，而不是同时给所有大陆增加浅层内容。建议以火山大陆为切片：

1. 目标：收集 3 枚火山余烬，唤醒沉睡的守护者。
2. 事件：救助迷路伙伴、熔岩岔路、获得“守护者会蓄力”的线索。
3. Boss：有明确蓄力与破盾回合，和地图线索相互呼应。
4. 结果：获得徽章、故事页与一种伙伴外观/称号，而不只增加数值。

## 4. 伙伴互动与亲子互动

### 伙伴互动

每次冒险结束后，玩家只能选择一项，不形成日常负担：聊天、练习、吃点心、拍照。连续完成 3 次不同互动，解锁称号、表情、剧情台词或伙伴技外观；不直接增加基础攻击力。

| 输入 | 产出 | 上限 |
| --- | --- | --- |
| 冒险结算后的互动选择 | 1 点默契 | 每次冒险 1 点 |
| 克制、破盾或救援事件 | 1 点默契 | 每次冒险最多 2 点 |
| 3 点默契 | 1 个纯外观/叙事奖励 | 不重复消耗 |

该资源只有来源和奖励出口，不出售、不强迫刷取；防止它变成消耗型货币或打卡任务。

### 亲子旁白模式

家长可开启旁白卡：每个事件给一句可朗读的环境描述；Boss 战前给一句敌人台词；结算后给一句总结。该模式不得改变伤害、掉落或难度，保证孩子单独玩时体验完整。

## 5. 奖励与收集

奖励呈现优先级：新伙伴/新图鉴 > 徽章/贴纸/故事页 > 新技能 > 经验与道具数量。每个结算页最多突出 3 项，避免奖励过多而失去记忆点。

| 资源 | 来源 | 用途 | 设计约束 |
| --- | --- | --- | --- |
| 精灵球 | 宝箱、任务、首次发现 | 捕捉伙伴 | 每次冒险至少有稳定获取途径 |
| 技能石 | Boss、少量宝箱 | 学习或替换技能 | 不作为必经刷取门槛 |
| 贴纸/徽章/故事页 | 大陆目标、首次事件、Boss | 相册与展示 | 不影响战斗强度 |
| 默契 | 互动、战术表现 | 外观与伙伴表现 | 无惩罚、无付费缺口 |

## 6. 交互与文案基线

- 首页只有一个最突出的下一步按钮，例如“继续冒险”。
- 地图顶部始终用一行展示“我现在要做什么”。
- 所有属性在面向玩家的地方均使用中文名与图标；不得暴露 `ground` 等内部代码。
- 战斗中的推荐、小心、克制和免疫采用统一文案来源，避免同一关系出现互相矛盾的提示。
- 失败使用“伙伴需要休息”，保留进度与收集成果，并给出下一步建议。

## 7. 迭代顺序与验收

| 阶段 | 交付 | 验收问题 |
| --- | --- | --- |
| P0 | 属性文案统一、战斗提示修复 | 是否完全不出现英文属性代码？ |
| P1 | 一个大陆的目标、选择事件与结算故事页 | 孩子能否复述“刚刚发生了什么”？ |
| P2 | Boss 线索与战斗机制联动 | 孩子能否说出“我为什么要这样打”？ |
| P3 | 伙伴互动、相册与亲子旁白 | 自创伙伴是否持续出现在冒险记忆中？ |
| P4 | 将已验证模板复制到其他大陆 | 每个大陆是否有不同主题、但不增加规则负担？ |

### 试玩假设

| 系统 | 假设 | 成功指标 |
| --- | --- | --- |
| 选择事件 | 有后果的二选一会提升故事记忆 | 试玩后能自主说出一次选择及结果 |
| 大陆目标 | 明确目标减少地图迷失 | 80% 的试玩中无需家长指出下一步 |
| 伙伴互动 | 轻量反应会提升自创价值 | 试玩后主动提及伙伴名字或特征 |
| 旁白模式 | 家长被邀请表演会增加共玩 | 家长可在不解释系统的前提下读完一局 |

## 8. 范围控制

当前不加入复杂装备、交易市场、抽卡、排行榜、强 PvP、大段剧情或双属性的复杂展示。优先证明“一个大陆、一次冒险、一个 Boss”已经好玩，再扩充内容。

## 9. 联机玩法待办（待排期）

联机目标不是让两位玩家对同一个目标轮流点技能，而是让孩子能够看见队友、商量打法、互相救援，并一起留下可回看的高光时刻。联机应始终支持单人可完成的保底路径；配合提供额外收益，不能成为唯一解法。

| 优先级 | 待办 | 验收标准 |
| --- | --- | --- |
| P0 | 队友意图提示：提交技能后显示“准备控制 / 爆发 / 守护 / 援护” | 已完成；队友卡片会在结算前显示准备的战术。 |
| P0 | Boss 意图：显示蓄力、横扫、毒雾等下一步威胁与简短反制建议 | 已完成；每回合 Boss 卡会显示意图与应对短句。 |
| P0 | 15 秒回合倒计时与自动保底行动 | 已完成；房主服务端到时自动补“自动守护”，不会永久等待。 |
| P0 | 联机 Boss 接入真实战斗结算：命中、属性克制/免疫、负面状态施加、持续伤害与行动失败 | 已完成；原生服务端已接入。 |
| P0 | 联机双属性结算：攻击面对双属性目标时，完整属性列表都参与克制与免疫判定 | 已完成；Boss 属性徽记与结算均使用完整属性列表。 |
| P1 | 默契能量与紧急救援 | 已完成；合击获得能量，3 点可在危险血量时恢复远征队并解除状态。 |
| P1 | 预设地图呼叫：如“发现 Boss！”“来帮我！”“这里有宝箱！” | 已完成；为 8 秒短呼叫，不开放自由聊天。 |
| P2 | 分路协作：线索路降低 Boss 压力，补给路提供恢复 | 已完成；开战前各自选一路，效果会带入共同 Boss 战。 |
| P2 | 共同捕获收尾：安抚、投球等两步互动 | 已完成；需要全员完成安抚、再全员投球。 |
| P2 | 共同冒险相册 | 已完成；胜利高光写入每名参与者的冒险日记。 |

### 联机战斗数值基线

| 项目 | 目标 |
| --- | --- |
| Boss 战时长 | 4–7 回合，约 2 分钟 |
| 单回合等待上限 | 15 秒 |
| 普通打法首次通关率 | 约 70% |
| 理解配合后的通关率 | 约 85% |
| 未凑连招时 | 仍造成约 90% 基础伤害 |
| 凑齐连招时 | 获得约 45% 额外伤害，或防守/救援效果 |

### 联机设计风险

- 不能把“推荐战术”设计成唯一正确按钮；不同组合都必须能推进战斗。
- 不能把等待队友变成主要玩法；倒计时与自动保底是基础体验的一部分。
- 奖励应个人独立结算，团队表现额外奖励贴纸、称号、捕获表现等，不制造抢奖励冲突。
- 暂不加入自由聊天、复杂交易、排行榜和强对抗，优先验证家庭共玩是否真的更有交流与故事感。

## 10.1 地图远征队与仓库

| 优先级 | 待办 | 状态 | 验收标准 |
| --- | --- | --- | --- |
| P1 | 每次进入一趟地图前，由孩子从仓库选择远征小队（人数不限） | 已完成，待平板试玩 | 孩子可以携带任意数量的伙伴；未被选中的伙伴不能进入本次地图战斗、野战或道馆；返回大陆重新进入地图时可重新配队。 |
| P1 | 让地图补给、经验与休息点只作用于本次远征小队 | 已完成，待平板试玩 | 仓库伙伴的 HP、经验与休眠状态不会被地图事件改变。 |
| P1 | 全部远征伙伴休眠或倒下时的失败出口 | 已完成，待平板试玩 | 强制撤退回大陆选择；保留已探索区域和已采集资源；远征队恢复至 50% HP；道馆失败造成的休眠倒计时不消失。 |

设计决定：这是一次**有边界的撤退**，而不是追加惩罚。孩子已经承受了战斗失败或道馆休眠的后果；再没收资源会让地图探索变成挫败。撤退的代价是结束本次配队和中断推进；队伍会回复到一半 HP，休眠倒计时则仍要等待。

## 11. 属性道馆系统（待实现）

> 详细策划、随机规则、同时 2v2/3v3、馆主与徽章数值见 [gym-system-design.md](./gym-system-design.md)。本节只保留任务摘要；其中早期“玩家选择规则、连续单挑”的旧设想已由独立策划案覆盖。

| 优先级 | 待办 | 状态 | 验收标准 |
| --- | --- | --- | --- |
| P2 | 实现属性道馆完整玩法：随机可达道馆格、馆主、固定 3–6 人馆内阵容随机出战、随机赛制、同时 1v1/2v2/3v3、徽章盒、休眠惩罚与 Boss 门槛 | 已完成，待平板试玩 | 满足 `gym-system-design.md` 的全部验收项；道馆首胜后才可挑战同地图 Boss。 |

### 目标与核心循环

道馆服务于“探索有目标、队伍有取舍、胜利有长期成果”三个支柱。它是每张地图中可选择的中期挑战，不替代大陆 Boss：

`地图中发现道馆 → 查看馆内阵容与挑战规则 → 选择 1v1 / 2v2 / 3v3 和换人规则 → 挑战 → 获得徽章并强化对应属性伙伴`

- 每张地图生成 **1 个** 与地图属性一致的道馆格；位置必须可到达、距离起点至少 3 格，且随机生成，不能形成固定跑图规律。
- 格子图标为“🏠 + 该地图属性图标”，进入格子后弹出道馆挑战卡，而不是直接开战。
- 自定义地图同样按其所选属性生成道馆；不可缺失。
- 每个道馆保存 3–6 只同属性馆内宝可梦，首次挑战后阵容不随机重置，方便孩子学习与复仇。

### 挑战界面与规则

玩家点击道馆后先显示：道馆名称、属性、馆内 3–6 只宝可梦剪影/已见信息、自己的可选伙伴，以及两个可调规则。玩家可选择“暂不挑战”返回地图，且不受惩罚。

| 规则 | 选项 | 规则说明 |
| --- | --- | --- |
| 对战规模 | 1v1 / 2v2 / 3v3 | 双方各从队伍/馆内阵容中派出对应数量；现有战斗保持轮流单挑，因此 2v2、3v3 是连续队伍战，不要求同时操作多只。 |
| 换人规则 | 自由换人 / 坚守到底 | 自由换人：可主动换伙伴，换人消耗本回合且新伙伴首回合减伤 30%。坚守到底：不允许主动换人，只有当前伙伴完全战败后才能派出下一只。 |

| 挑战规模 | 馆主出战数量 | 敌方等级基线 | 预计时长 |
| --- | ---: | --- | --- |
| 1v1 | 1 | 玩家所选伙伴平均等级 + 0 | 1–2 分钟 |
| 2v2 | 2 | 第 1 只 +0，第 2 只 +1 | 2–3 分钟 |
| 3v3 | 3 | +0、+1、+1 | 3–5 分钟 |

馆内完整阵容数量根据地图难度确定：简单为 3 只、困难为 4 只、地狱为 5 只；获得 8 枚徽章后，道馆大师复赛开放第 6 只。未被选入本局的馆内宝可梦仍展示在挑战卡中，形成“下一次该怎样配队”的信息。

### 徽章强化与奖惩

首次成功挑战获得该属性的 **徽章印记 ×1**。立即或之后都可交给一只拥有该属性的伙伴，选择强化一个属性；同一枚徽章不可重复领取，复赛改发经验、贴纸和外观称号，避免无限刷数值。

| 强化选项 | 效果 | 限制 |
| --- | --- | --- |
| 体力刻印 | 最大 HP +6 | 每只伙伴最多 2 枚徽章印记 |
| 攻击刻印 | 攻击 +4 | 同一伙伴不能重复选择同一项 |
| 防御刻印 | 防御 +4 | 同一伙伴不能重复选择同一项 |
| 速度刻印 | 速度 +3 | 同一伙伴不能重复选择同一项 |

双属性伙伴可接受其任一属性的徽章；例如地面 + 超能力伙伴可以选择地面或超能力道馆徽章，但最多装 2 枚且属性强化不能重复。这让收集和配队有价值，又不会出现把所有徽章堆到一只伙伴攻击上的唯一最优解。

| 结果 | 后果 |
| --- | --- |
| 挑战成功 | 获得对应属性徽章印记、经验、首次通关故事记录；可立刻选择强化或以后在伙伴页操作。 |
| 挑战失败 | 从本次实际出战的伙伴中随机选择 1 只，进入 **10 分钟休眠期**；不可参加战斗，但不会扣除道具、经验、已获得徽章或地图进度。 |
| 未挑战/主动退出规则选择页 | 无惩罚。 |

失败结算必须明确显示“哪一只伙伴在休息、何时恢复”，并给出一条下一次建议，例如“试试带水属性伙伴挑战红莲道馆”或“改用自由换人规则”。

### 实现顺序与试玩验收

| 优先级 | 交付 | 试玩假设与验收 |
| --- | --- | --- |
| P1 | 新增 `gym` 地图格、随机且可达的摆放、属性房屋图标、挑战/暂不挑战弹窗 | 孩子可自行找到道馆，并能说出“这是哪种属性道馆”。 |
| P1 | 1v1 与自由换人规则、首次徽章与单项强化 | 80% 试玩者能自行完成一次“选伙伴—挑战—强化”的完整循环。 |
| P2 | 2v2、3v3、坚守到底规则、馆内 3–6 人阵容 | 有经验的 10 岁玩家会主动因规则不同调整队伍，而不是永远选同一只高等级伙伴。 |
| P2 | 失败休眠、复赛、徽章展示与故事记录 | 失败后仍愿意在恢复后再次挑战，不因 10 分钟惩罚退出游戏。 |

### 风险控制

- 道馆不能全部生成在同一个角落；沿用 Boss 的“随机且可到达”校验。
- 徽章不能无限刷数值；首次通关才产出印记，且每只伙伴最多 2 枚、同项不可重复。
- 3v3 不应仅是三倍血量；通过换人规则、对手顺序和属性队伍制造战术差异。
- 初次进入道馆默认推荐 1v1 + 自由换人；更难规则由玩家主动选择，避免 7 岁孩子误入挫败局。
