# 商店与精灵球经济规划

## 设计前提

- 本规划默认钻石只是游戏内资源，不接入现金购买。
- 设计支柱：亲子友好的清晰选择、探索有持续回报、稀有资源有成长感。
- 核心循环：探索地图 → 战斗/开宝箱获得钻石和资源 → 在商店补给 → 捕获与培养伙伴 → 挑战更高难度。

## 当前精灵球掉落检查

战斗奖励每次先随机生成 1～3 个球。当前实现使用 `0～100` 的随机数，却按 `70、70、70、20、20、8、2` 依次累计权重；第二项累计值已经达到 140，因此后面的类型永远不会被选中。

| 类型 | 当前每次抽取的真实概率 | 当前能否随机掉落 |
|---|---:|---|
| 普通球 | 100% | 能 |
| 高级球 | 0% | 不能 |
| 超级球 | 0% | 不能 |
| 大师球 | 0% | 不能 |
| 传奇球 | 0% | 不能 |
| 超限球 | 0% | 不能 |

因此，普通战斗胜利当前固定得到 1～3 个普通球，平均 2 个。现有概率数组表面上像是想表达“普通 70%、高级 20%、超级 8%、大师 2%”，但类型重复与总权重处理同时出错。

其他固定来源：

| 来源 | 奖励 |
|---|---|
| 新训练师 | 普通球 ×3、高级球 ×1 |
| 首次完成普通章节任务 | 普通球 ×1 |
| 首次完成 Boss 章节任务 | 高级球 ×1 |
| 每日任务 | 通常为普通球 ×1；捕获任务为高级球 ×1 |
| 联机合作胜利 | 普通球 ×1 |

超级球、大师球、传奇球、超限球目前都没有有效的稳定产出渠道。

## 建议掉落表

保留每场胜利掉落 1～3 个球的规则，但把每个球的类型改为一张总和为 100% 的唯一权重表：

| 类型 | 建议单球概率 | 平均每场数量 | 每场至少出现一个的概率 |
|---|---:|---:|---:|
| 普通球 | 简单 76% / 困难 64% / 地狱 50% | 简单 1.52 / 困难 1.28 / 地狱 1.00 | 难度越高越少 |
| 高级球 | 20% / 24% / 25% | 0.40 / 0.48 / 0.50 | 难度越高越多 |
| 超级球 | 3.5% / 8% / 14% | 0.07 / 0.16 / 0.28 | 难度越高越多 |
| 大师球 | 0.5% / 3% / 7% | 0.01 / 0.06 / 0.14 | 难度越高越多 |
| 传奇球 | 0% / 0.8% / 3% | 0 / 0.016 / 0.06 | 困难开始掉落 |
| 超限球 | 0% / 0.2% / 1% | 0 / 0.004 / 0.02 | 困难开始极低概率掉落 |

这张表让全部六类球都能自然产出，同时保持传奇球和超限球的稀有感。困难与地狱难度第一版先不额外改变掉率，避免同时调整过多变量；后续可根据实际库存数据增加难度加成。

## 商店第一版

入口放在主页，并在背包顶部提供“去商店”快捷按钮。商店顶部固定显示当前训练师和钻石余额，购买后立即更新余额与背包数量。

| 商品 | 价格 | 解锁条件 | 购买规则 |
|---|---:|---|---|
| 普通球 ×1 | 💎 120 | 默认 | 可选 1/5/10 个 |
| 高级球 ×1 | 💎 360 | 默认 | 可选 1/5/10 个 |
| 超级球 ×1 | 💎 900 | 获得 1 枚道馆徽章 | 可选 1/5 个 |
| 大师球 ×1 | 💎 2,600 | 获得 3 种属性道馆徽章 | 每次买 1 个 |
| 传奇球 ×1 | 💎 6,500 | 获得 7 种属性道馆徽章 | 每次买 1 个 |
| 超限球 ×1 | 💎 15,000 | 曾成功合成超级勋章 | 每次买 1 个 |

现有存档可以长期积累数千钻石，因此商店定位为长期资源回收口，而不是新手获取精灵球的唯一方式。常用球仍由战斗和任务提供保底，商店主要服务于批量补货与高阶球兑换。

## 购买交互

1. 点商品卡片后先选择数量，按钮同时显示总价。
2. 余额不足时不允许确认，并直接显示“还差多少钻石”。
3. 稀有商品未解锁时保留展示，显示需要的徽章条件，不隐藏目标。
4. 确认购买后同时扣钻石、增加当前训练师的对应库存，再播放一次简短入袋动画。
5. 返回背包时立即看到新数量；不同训练师的余额和库存必须继续隔离。
6. 购买过程必须是一次完整事务，不能出现扣了钻石却没收到物品的状态。

## 捕获价值参考

当前捕获公式的平均成功率如下；实际单次结果还会有 ±15% 随机波动，并统一封顶 95%。

| 类型 | 满血 | 半血 | 约 10% HP |
|---|---:|---:|---:|
| 普通球 | 15% | 22.5% | 28.5% |
| 高级球 | 22.5% | 33.8% | 42.8% |
| 超级球 | 30% | 45% | 57% |
| 大师球 | 45% | 67.5% | 约 85.3% |
| 传奇球 | 60% | 约 88.7% | 95% |
| 超限球 | 75% | 95% | 95% |

传奇球和超限球在低血量时都会触及 95% 上限，所以价格差主要购买的是“更早投球也有高成功率”的便利，而不是低血量下更高的上限。

## 风险与防护

- **普通球膨胀**：战斗平均仍产出 1.36 个普通球；上线后若多数玩家库存持续超过 30，应降低普通球掉率，而不是继续降价。
- **稀有球碾压捕获玩法**：传奇球与超限球按徽章进度解锁，并保持高价，避免玩家从开局开始无脑投高阶球。
- **钻石饥饿**：医院和商店共用钻石。若玩家因为治疗而连续 3 场以上没有球可用，应下调普通球价格或提高任务保底。
- **测试缺口**：现有测试只检查数量和类型是否合法。实现时需要增加权重边界测试、六类可达性测试、概率总和测试和购买原子性测试。
- **范围控制**：第一版不新增药水、复活道具或每日刷新货架，以免削弱医院和休息点的作用。

## 上线验证指标

| 系统 | 假设 | 成功指标 |
|---|---|---|
| 精灵球掉落 | 常用球够用，稀有球值得期待 | 边界测试证明六类均可达；100 万次模拟误差在目标概率 ±0.1% 内 |
| 商店 | 钻石获得了持续且可理解的用途 | 试玩 30 分钟内至少完成 1 次购买，且无需因缺球停止冒险 |
| 价格 | 玩家会在治疗和补给间作选择 | 钻石支出中商店占 40%～70%，医院仍有实际使用 |
| 解锁 | 稀有商品强化徽章成长感 | 获得新解锁时玩家能看懂原因，并能在 10 秒内找到对应商品 |

## 实现交接

- 新增独立商店页面与主页、背包入口。
- 建立一份可调的商品配置表，包含商品、数量、价格、解锁条件和展示顺序。
- 修正掉落权重抽样，类型不可重复，权重总和必须由程序计算或断言为 100。
- 统一通过训练师库存方法完成购买，补充精灵球保存方法，避免页面各自拼接存储键。
- 为旧存档保留现有精灵球数量，不做清零或折算。
