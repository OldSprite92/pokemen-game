# 美术实现规范

**当前美术风格：手绘卡通。**

本规范适用于游戏中所有玩家可见的画面，包括地图、角色、伙伴、道具、建筑、地面、墙壁、UI 图标和特效。

## 核心原则

1. 玩家看得到的物体必须优先使用贴图、精灵图、SVG 美术资源或生成图片；不能把矩形、圆形、纯色块、文字或 CSS 图形当作最终美术。
2. 代码只负责资源加载、定位、缩放、分层、碰撞、动画、交互和状态变化。
3. 原始几何图形只允许用于调试、碰撞盒或临时占位。任何临时占位都要标明“临时占位”，并写清后续需要替换的具体素材。
4. 每个物体先拆分资源需求，再实现逻辑。例如装水瓶子至少需要瓶身、瓶口/高光，以及空、半满、装满的水位贴图或遮罩。
5. 全项目统一手绘卡通的色板、描边、光照方向与像素密度；新素材先说明视觉规格，再制作或接入。
6. 每完成一个界面或场景，进行视觉验收：去掉交互逻辑后，画面本身也应像完成度较高的游戏；若不成立，先补齐美术资源，不用基础图形敷衍。

## 每次制作的固定顺序

1. 输出该界面/场景的素材清单：名称、尺寸、状态、用途、层级与视觉说明。
2. 创建或接入资源，并确认授权和风格一致性。
3. 使用代码完成摆放、状态切换、动画和交互。
4. 截图检查视觉完整度；将未完成资源显式列为临时占位。

## 素材清单模板

| 素材 | 尺寸 | 状态/变体 | 用途 |
| --- | --- | --- | --- |
