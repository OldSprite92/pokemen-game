# 宝可梦大冒险：轻策略战斗系统设计

> 目标：让有经验的 10 岁玩家能通过读局势、属性反制、状态和换人赢得战斗；让初次接触的孩子仍能依靠清晰提示完成普通战斗。

## 1. 战斗支柱与循环

1. **读局势。** 敌方行动可预测，正确判断应获得明确收益。
2. **做组合。** 技能、属性、状态、换人和伙伴能量相互配合，不能由单一高伤害技能垄断。
3. **打得快而有戏。** 普通战斗在 45–90 秒结束；Boss 战在 2–4 分钟内完成并有可识别的阶段。

```text
查看敌方意图 → 选择进攻 / 战术 / 防守或换人
  → 触发克制、状态或打断 → 敌方按意图行动
  → 获得下一回合的新判断
```

## 2. 现状问题与设计结论

| 现状 | 问题 | 迭代方向 |
| --- | --- | --- |
| 敌方随机选技能 | 玩家只能猜，难以形成预判成就 | 显示简短意图；Boss 使用循环 |
| 伤害下限固定为 10 | 不利属性仍常造成接近普通伤害 | 降低非免疫攻击下限，拉开属性区间 |
| “推荐”可因命中率而获得伙伴能量 | 容易演化为一直点绿色标签 | 能量只奖励克制、破盾、打断等战术成功 |
| 状态存在但不够可读 | 玩家难以围绕状态做计划 | 技能卡、敌方意图、战斗日志均展示状态价值 |

## 3. 敌方意图与 Boss 阶段

普通敌人在本回合显示一个意图图标与短句；不显示精确伤害和完整技能名称。Boss 按固定或半固定的两至三回合模式行动，并在第一次出现时用安全场景教学。

| 意图 | 敌方行为 | 有效反制 | 反馈 |
| --- | --- | --- | --- |
| 蓄力 | 下一回合高伤害攻击 | 克制攻击打断、使用防守、换人 | “蓄力被打断！” |
| 毒雾 | 施加持续伤害 | 先手打断、解除状态、换人 | “毒雾被吹散了！” |
| 岩石盾 | 受到普通攻击伤害减半 | 对应属性破盾、使用战术技 | “护盾碎掉了！” |
| 疲惫 | 本回合伤害降低 | 使用爆发技或捕捉 | “现在是进攻机会！” |

Boss 模板应使用“教学 → 组合 → 变化 → 休息”的节奏：首回合无惩罚地展示机制，第二次才要求玩家处理，阶段结束给一个明显进攻窗口。

## 4. 技能、状态和换人

每只伙伴保留 3–4 个技能，技能必须有职能差异。玩家不需要理解公式，但技能卡使用图标和一句短提示说明用途。

| 技能类别 | 建议伤害/命中 | 附加规则 | 作用 |
| --- | --- | --- | --- |
| 稳定技 | 14–18 / 95–100% | 无或轻效果 | 保底、收尾 |
| 爆发技 | 24–28 / 75–85% | 无状态或小代价 | 利用敌方疲惫/破盾窗口 |
| 战术技 | 10–16 / 90–100% | 状态、破盾、减伤或打断 | 创造下一回合优势 |
| 伙伴技 | 消耗 3 点能量 | 强攻、打断或救援三选一 | 对战术成功的奖励 |

状态不应只是随机扣血：

| 状态 | 基础效果 | 玩家可利用的时机 |
| --- | --- | --- |
| 灼伤 | 3 回合，每回合 4% 最大 HP | 降低耐久敌人的压力 |
| 中毒 | 3 回合，每回合 6% 最大 HP | 对高护盾 Boss 持续施压 |
| 麻痹 | 持续 2 回合，敌方速度/行动效果降低 | 争取爆发或换人窗口 |
| 冰冻/恐惧 | 跳过或弱化 1 次行动 | 明确提示“现在适合进攻” |
| 缠绕 | 2 回合，持续伤害且不易换人 | 阻止敌人拖延或强化 |

主动换人消耗本回合；新伙伴在入场这一回合受到的伤害降低 30%。换人必须是防守和属性调整的可行选择，不能只在伙伴倒下后使用。

## 5. 伤害与难度目标

以下数值是首轮可调基线，以 100 最大 HP 为例。除免疫外，伤害下限建议为 4，随机浮动不超过 ±10%；避免现有固定 10 点下限掩盖不利属性差异。

| 效果 | 单次伤害目标 | 击败 100 HP 对手所需有效命中 | 体验 |
| --- | ---: | ---: | --- |
| 不利 | 7–12 | 9–14 次 | 可以应急，但不应长期硬磨 |
| 普通 | 16–22 | 5–7 次 | 稳定推进 |
| 克制 | 28–36 | 3–4 次 | 选对属性有明显回报 |
| 破盾后爆发 | 32–36 | 2–3 次 | 正确处理机制后的高潮 |

| 遭遇类型 | 回合/时长目标 | 首次通关胜率目标 | 失败成本 |
| --- | --- | ---: | --- |
| 普通野生伙伴 | 3–5 个玩家决策 / 45–90 秒 | 80–90% | 保留进度，轻恢复 |
| 精英遭遇 | 5–7 个决策 / 1–2 分钟 | 65–80% | 给出属性或队伍建议 |
| Boss | 7–10 个决策 / 2–4 分钟 | 55–70% | 回到检查点，不扣奖励/伙伴 |

高难度应增加机制组合、敌方数值和选择压力，而不是单纯提高血量；否则会变成无聊的硬磨。

## 6. 伙伴能量经济

伙伴能量是战斗内资源，不跨战斗储存。

| 项目 | 规则 |
| --- | --- |
| 来源 | 命中克制、成功破盾、成功打断，各 +1 |
| 上限 | 3 点 |
| 消耗 | 伙伴技消耗全部 3 点 |
| 出口 | 强攻、打断、救援三种伙伴技效果之一 |
| 禁止来源 | 仅因“推荐”、普通命中或纯等待获得 |

这保证来源来自主动理解，而出口制造一次值得期待的高潮；玩家无法靠重复稳定技无风险刷满能量。

## 7. 信息设计

- 技能卡同时显示属性图标、用途图标和一句话；“推荐”是建议，不是唯一正确答案。
- 克制提示使用中文属性名与图标；免疫时明确说明原因，例如“地面属性把电流引走了”。
- 敌方意图固定在战斗区域上方，不能被日志淹没。
- 状态在角色旁以图标、剩余回合和一句效果显示。
- 战斗日志只显示最近 3–5 条，重要的破盾、打断、暴击、状态以单独浮层强调。

## 8. 实现次序、风险与试玩

| 优先级 | 内容 | 试玩假设 | 成功指标 |
| --- | --- | --- | --- |
| P0 | 修复属性文案与统一提示 | 玩家不会因文案误解属性关系 | 所有战斗文本中无英文属性代码 |
| P1 | 敌方意图 + 1 个蓄力/打断 Boss | 可预判的信息能形成主动策略 | 试玩者至少一次主动打断蓄力 |
| P2 | 调整伤害下限、克制区间、技能职能 | 属性与技能选择会明显改变结果 | 克制技能使用率高于不利技能，且不是 100% |
| P3 | 状态可视化、主动换人、伙伴能量 | 队伍与战术技能成为常用选项 | Boss 战中至少使用一次非纯伤害行动 |
| P4 | 为各大陆加入不同 Boss 模板 | 内容复用机制而不重复体验 | 每个 Boss 有可复述的独特规则 |

主要风险：

- **推荐标签变成唯一答案。** 用“为什么推荐”的短提示与可行的战术替代方案解决。
- **机制叠加过快。** 每个大陆只新增一个核心概念，先教学后组合。
- **只堆血量。** 以回合数和可处理的意图提升难度，不以硬磨提升难度。
- **功能膨胀。** 当前不加入天气、复杂装备、多个资源条或双属性计算展示。

## 9. 实现交接摘要

```yaml
pillars:
  - 看懂局势并主动反制
  - 技能、队伍与伙伴协作带来胜利
core_loop: 查看意图 -> 做出战术选择 -> 获得可见反馈 -> 处理下一轮意图
first_vertical_slice:
  - 一种敌方蓄力意图
  - 一种可打断的 Boss
  - 统一的中文属性提示
  - 可调伤害上下限与克制倍率
acceptance:
  - 普通战斗 45–90 秒
  - Boss 战 2–4 分钟
  - 玩家能说出一次换人、破盾或打断的理由
```
