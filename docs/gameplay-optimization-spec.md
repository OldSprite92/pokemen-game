# 宝可梦大冒险：7岁儿童向可玩性优化 Spec

## 1. 项目背景

本项目服务于一个7岁孩子的亲子想象游戏：孩子会自创宝可梦的名字、属性、技能，并和爸爸妈妈一起进行口头角色扮演、冒险和对战。当前游戏已经把“创造宝可梦、选择训练师、地图冒险、遭遇野怪、回合制战斗、捕获、图鉴、奖励”做成了可玩的基础框架。

本 spec 的目标不是增加复杂硬核系统，而是让游戏更像孩子自己的冒险故事：更容易开始、更有反馈、更有目标、更适合亲子一起玩。

## 2. 目标玩家

- 核心玩家：7岁孩子，识字能力有限，喜欢想象、自创、收集、胜利反馈。
- 陪玩玩家：爸爸妈妈，负责读文字、解释规则、参与角色扮演、帮助做选择。
- 单局时长目标：3-8分钟完成一次小冒险或一场战斗。
- 难度目标：孩子大多数时候能赢；失败也像“休息一下再来”，不能有强惩罚。

## 3. 当前项目现状

### 已有能力

- 可以创建训练师并选择初始伙伴。
- 可以自创宝可梦：名字、属性、技能、形象、数值。
- 有多个大陆地图，地图包含野怪、宝箱、休息点、Boss、障碍物。
- 有回合制战斗、属性克制、命中、暴击、经验、升级。
- 有捕获系统、精灵球、技能石、图鉴和遭遇记录。
- 有家庭联机/多人入口。

### 主要体验问题

- 冒险和故事的连接较弱：走格子、触发事件、进入战斗之间缺少“为什么”的故事感。
- 战斗选择对7岁孩子仍偏抽象：技能威力、命中、属性克制需要更直观的提示。
- 奖励主要是数值和道具，缺少孩子能马上讲出来的成就感。
- 地图随机性较强，但目标感不足：孩子不一定知道“我现在要去哪里、为什么去”。
- 创建宝可梦很符合项目核心，但自创内容在后续冒险中的“被看见感”还可以加强。
- 项目里部分中文文本存在乱码风险，实际 APK 中若出现乱码会显著影响儿童体验。

## 4. 核心设计原则

1. 少规则，多反馈  
   不让孩子记复杂规则，而是在选择时直接告诉他“这个很有效”“这个有点危险”。

2. 小目标，快奖励  
   每次打开游戏都能完成一个小任务：找到宝箱、打败一只野怪、捕获一个伙伴、点亮一格图鉴。

3. 想象优先于平衡  
   自创名字、自创技能、自创故事比数值平衡更重要。数值只负责让游戏不崩。

4. 失败温柔化  
   失败不叫“输惨了”，而是“伙伴累了，需要休息”。给出恢复、再挑战、换伙伴的路径。

5. 亲子共玩友好  
   允许家长读故事、孩子做选择。系统可以提供“讲故事提示词”，让爸爸妈妈接着演。

## 5. 优先级路线图

### P0：先修复基础体验

- 修复所有中文乱码，保证按钮、提示、战斗日志、图鉴说明可读。
- 首页增加“继续冒险”主按钮，减少孩子每次重新找入口。
- 战斗结束后能明确回到当前地图，不打断冒险连续性。
- 奖励弹窗关闭后自动完成战斗收尾，避免孩子不知道下一步点哪里。

### P1：提升可玩性但不增加难度

- 战斗技能按钮增加儿童化提示：推荐、普通、小心。
- 地图增加“今日小任务”：例如“找到1个宝箱”“遇见1只新伙伴”“挑战火山Boss”。
- 每个大陆增加一句明确目标和一位守护Boss故事。
- 宝箱奖励改成更有情绪的内容：贴纸、称号、故事碎片、精灵球。
- 图鉴增加“我的发现”进度，例如“火山岛发现 3/8”。

### P2：强化孩子的自创感

- 创建宝可梦时增加“它的性格”和“它最喜欢什么”两个轻量字段。
- 冒险事件中引用孩子自创宝可梦的名字和技能。
- 战斗胜利后生成一句“今日冒险故事”，可保存在图鉴或冒险日记。
- 允许家长帮助创建“家庭Boss”或“爸爸妈妈角色”。

### P3：长期可玩内容

- 每个大陆做成3个阶段：探索、守护者试炼、Boss挑战。
- 增加贴纸册/徽章墙，收集目标不只依赖战斗。
- 增加亲子模式：孩子选择行动，家长选择旁白或敌人台词。
- 增加轻量任务链，例如“帮助冰雪大陆找回雪花钥匙”。

### P4：地图多难度复玩层

- 每个大陆增加“简单、困难、地狱”三档难度，让同一张地图可以反复挑战。
- 简单难度始终开放；困难建议通关该大陆简单后开放；地狱建议通关困难后开放，同时保留家长手动解锁。
- 难度只改变敌人强度、地图风险、补给数量和奖励稀有度，不增加复杂规则。
- 高难度失败不惩罚孩子，只表达为“伙伴累了，先回营地休息”，避免挫败。

## 6. 具体功能规格

### 6.1 首页：儿童主路径

目标：孩子打开游戏后，第一眼知道该点哪里。

需求：

- 如果存在未完成冒险，首页第一主按钮显示“继续冒险”。
- 如果没有训练师，首页第一主按钮显示“创建训练师”。
- 如果有训练师但没有自创宝可梦，首页推荐“创造我的第一只宝可梦”。
- 首页保留入口：创造、冒险、对战、图鉴、训练师。
- 每个入口使用大图标、大按钮、短文本。

验收标准：

- 7岁孩子不读说明也能找到主要按钮。
- 首页不出现长段玩法说明。
- 按钮文本不超过8个汉字，必要时可用两行。

### 6.2 创建宝可梦：增强想象表达

目标：让孩子感觉这是“我发明的伙伴”，不是只填表。

新增字段：

- 性格：勇敢、调皮、温柔、聪明、爱吃、害羞。
- 喜欢的东西：自由输入，最多10个汉字。
- 口头禅/叫声：自由输入，最多10个汉字。

体验规则：

- 这些字段不影响战斗强度。
- 在图鉴、战斗开场、冒险事件中随机出现。
- 技能仍允许孩子自定义名字和描述。

示例文案：

- “火花龙跳了出来，大喊：我要喷火！”
- “因为喜欢草莓，小粉猪在宝箱旁边闻了又闻。”

验收标准：

- 创建流程新增内容不超过1个步骤，避免流程变长。
- 可以跳过性格/喜欢/叫声。
- 图鉴详情中能看到这些设定。

### 6.3 地图冒险：增加目标感

目标：地图不是随机点格子，而是一段小故事。

新增“大陆目标”：

- 每个大陆有一个主目标，例如“找到火山徽章”“帮冰雪女王恢复雪花水晶”。
- 地图顶部显示当前目标，最多一行。
- Boss 格子变成阶段目标的终点。

新增“今日小任务”：

- 每天或每次进入冒险生成1-3个简单任务。
- 任务例子：
  - 找到1个宝箱。
  - 打败1只野生宝可梦。
  - 捕获1个新伙伴。
  - 到达1个休息点。
  - 看见1只没见过的宝可梦。

奖励：

- 小任务奖励少量经验、普通精灵球、贴纸或故事碎片。
- 奖励不应强迫孩子刷。

验收标准：

- 地图页面始终显示“我现在要做什么”。
- 单个任务可在3-8分钟内完成。
- 任务失败或离开页面不惩罚。

### 6.3.1 地图难度层：简单 / 困难 / 地狱

目标：让孩子玩腻同一个大陆后，可以用更刺激的版本重新挑战，同时不让高难度破坏轻松冒险的主体验。

推荐解锁方式：

- 简单：默认开放，所有孩子都能直接进入。
- 困难：通关该大陆简单难度后开放；如果孩子已经有2只4级以上伙伴，也可以提前开放。
- 地狱：通关该大陆困难难度后开放；家长可以在设置里手动解锁。

不建议所有难度一开始完全开放，因为7岁孩子很容易误点最高难度，然后觉得“游戏坏了”或“我不会玩”。也不建议全局线性锁死，因为孩子可能特别喜欢某个大陆，想反复挑战它。因此采用“每个大陆独立解锁 + 家长可解锁”的混合方案。

三档难度区别：

| 难度 | 面向体验 | 敌人强度 | 地图变化 | 奖励 |
| --- | --- | --- | --- | --- |
| 简单 | 轻松探索，适合孩子自己玩 | 敌人与玩家等级接近，Boss略弱 | 宝箱和休息点更多，随机战斗较少 | 基础经验、普通贴纸、大陆徽章 |
| 困难 | 有选择的挑战，适合亲子一起玩 | 敌人高1-2级，Boss更耐打 | 随机战斗更多，休息点减少 | 更多经验、稀有贴纸、徽章亮边 |
| 地狱 | 高成就试炼，适合熟练后挑战 | 敌人高3-4级，Boss有更强技能组合 | 宝箱更少，危险事件更多，路线更紧张 | 大量经验、限定贴纸、勇者徽章边框 |

儿童友好限制：

- 地狱难度不要使用恐怖画面或惩罚文案，界面上可显示为“地狱 / 勇者试炼”。
- 失败不扣贴纸、不扣徽章、不删除伙伴。
- 地狱难度只提供收藏外观奖励，不提供必须刷的核心成长奖励。
- 地图入口默认停留在“简单”或上次成功游玩的难度。

数据结构建议：

```ts
type MapDifficulty = 'easy' | 'hard' | 'hell';

type ContinentDifficultyProgress = {
  continentId: string;
  difficulty: MapDifficulty;
  completed: boolean;
  bossDefeated: boolean;
  bestClearDate?: string;
  rewardClaimed: boolean;
};
```

配置模块建议：

- 新增 `mapDifficultyConfig.ts`。
- 每个难度配置：敌人等级偏移、Boss属性倍率、随机战斗概率、宝箱概率、休息点概率、奖励倍率、限定贴纸池。
- 旧存档没有难度字段时，默认按 `easy` 处理。

### 6.4 冒险事件：增加亲子旁白

目标：把格子事件变成适合爸爸妈妈读出来的小剧场。

事件类型：

- 野怪出现：一只宝可梦从草丛/雪地/岩浆旁跳出来。
- 宝箱发现：孩子打开宝箱，获得道具或故事碎片。
- 休息点：伙伴吃点心、睡一觉、恢复体力。
- 神秘事件：获得线索、遇到NPC、听见Boss声音。
- Boss事件：进入守护者挑战。

事件文案规则：

- 每条文案控制在1-2句。
- 使用孩子能懂的词，不使用复杂系统词。
- 给家长留表演空间，例如“你要怎么回答它？”

示例：

- “草丛晃了一下，一只闪电蜥蜴跳出来挡住了路。它看起来不是坏蛋，只是想比试一下。”
- “你发现一个发光宝箱。里面有一张火焰贴纸和一个普通精灵球。”

验收标准：

- 每种格子至少有3条随机文案。
- 文案能引用大陆、玩家宝可梦、野怪名字。
- 事件弹窗提供明确按钮：战斗、试着捕获、离开、收下。

### 6.5 战斗：儿童友好的策略提示

目标：保留回合制乐趣，但降低理解成本。

技能按钮新增提示：

- “推荐”：属性克制或伤害预估较好。
- “普通”：正常伤害。
- “小心”：效果不好、可能无效或命中较低。

提示展示：

- 用颜色和短词，不展示复杂公式。
- 可显示一句短解释，例如“火对草很有效”。

难度规则：

- 普通冒险中，孩子胜率目标为70%-85%。
- 早期野怪等级不高于玩家最高等级+1。
- Boss 可以更强，但必须给休息点或提示。
- 失败后自动恢复部分HP，提示“伙伴累了，休息一下再挑战”。

战斗节奏：

- 敌方行动等待时间控制在0.8-1.2秒。
- 战斗日志只显示最近3-5条。
- 胜利奖励弹窗必须有“继续冒险”按钮。

验收标准：

- 孩子能通过“推荐”按钮打出明显效果。
- 不需要理解攻击、防御公式也能玩。
- 一场普通战斗不超过2分钟。

### 6.6 捕获：让收集更快乐

目标：捕获不只是概率，而是惊喜时刻。

优化规则：

- 敌方HP越低，捕获提示越积极。
- 捕获失败时给鼓励文案，不要让孩子沮丧。
- 每次冒险至少能较稳定地获得普通精灵球。

捕获提示：

- “机会很大！”
- “可以试试看。”
- “它还很有精神，可能会挣脱。”

捕获成功后：

- 弹出欢迎卡片：名字、属性、等级、它的一句介绍。
- 如果是首次捕获该种类，点亮图鉴并给贴纸。

验收标准：

- 普通球在低血量时有明显成功机会。
- 捕获成功后自动加入训练师队伍。
- 图鉴能显示“已遇见/已捕获”状态。

### 6.7 奖励系统：从数值奖励变成情绪奖励

目标：孩子能记住“我得到了什么好东西”。

奖励类型：

- 经验：用于升级。
- 精灵球：用于捕获。
- 技能石：学习新技能。
- 贴纸：纯收集，不影响数值。
- 徽章：完成大陆或Boss后获得。
- 故事碎片：收集后解锁一段大陆故事。

奖励展示优先级：

1. 新伙伴/新图鉴。
2. 新徽章/贴纸。
3. 升级/学会新技能。
4. 道具数量。

验收标准：

- 奖励弹窗每次最多展示4条主要奖励。
- 重要奖励有大图标和短文案。
- 升级时明确显示“变强了哪里”，例如“HP +4”。

### 6.8 图鉴：变成孩子的作品册

目标：图鉴不是仓库，而是孩子创造和发现的收藏册。

新增结构：

- 我的伙伴：孩子创造和捕获的宝可梦。
- 遇见过：冒险中见过但未捕获的宝可梦。
- 贴纸册：收集到的贴纸。
- 冒险日记：自动保存的短故事。

图鉴详情：

- 名字、属性、等级、形象、技能。
- 性格、喜欢、叫声。
- 第一次遇见地点。
- 第一次胜利或捕获时间。
- 家长可读的一句话介绍。

验收标准：

- 孩子能在图鉴里找到自己创造的宝可梦。
- 遇见但没捕获的宝可梦也有记录。
- 图鉴进度能按大陆显示。

### 6.9 亲子模式

目标：让爸爸妈妈自然参与，而不是只看孩子点按钮。

模式入口：

- 首页或设置中增加“亲子旁白模式”开关。

开启后：

- 冒险事件多显示一句“家长旁白提示”。
- Boss战前给家长一句敌人台词。
- 胜利后生成一句可读的冒险总结。

示例：

- 家长旁白提示：“请问孩子：你想悄悄绕过去，还是勇敢挑战？”
- Boss台词：“我是火山守护者！只有勇敢又善良的训练师才能通过！”

验收标准：

- 不影响孩子独自游玩。
- 文案短，适合家长现场发挥。
- 不加入复杂多人规则。

## 7. 数值与难度建议

### 等级

- 最高等级暂定10级，适合短期成长。
- 1-3级：教学期，基本都能赢。
- 4-7级：普通冒险期，开始需要看推荐技能。
- 8-10级：Boss挑战期，允许一点点失败和重试。

### 伤害

- 普通技能约造成敌方最大HP的15%-30%。
- 克制技能约造成25%-45%。
- 效果不好技能约造成8%-18%。
- 不建议出现一击秒杀，除非是剧情技能。

### 失败

- 普通战斗失败：返回地图或休息点，恢复50% HP。
- Boss失败：提示“再找一个宝箱或休息点会更容易”。
- 不删除道具、不扣经验、不让孩子损失已捕获宝可梦。

### 地图难度数值建议

| 项目 | 简单 | 困难 | 地狱 |
| --- | --- | --- | --- |
| 普通敌人等级 | 玩家平均等级 -1 到 +1 | 玩家平均等级 +1 到 +2 | 玩家平均等级 +3 到 +4 |
| Boss HP倍率 | 0.9x | 1.2x | 1.5x |
| Boss攻击倍率 | 0.9x | 1.15x | 1.35x |
| 随机战斗概率 | 低 | 中 | 高 |
| 宝箱数量 | 多 | 中 | 少 |
| 休息点数量 | 多 | 少 | 很少 |
| 经验奖励 | 1.0x | 1.35x | 1.75x |
| 贴纸奖励 | 普通贴纸 | 普通+稀有贴纸 | 稀有+限定贴纸 |

推荐体验目标：

- 简单胜率：80%-90%，孩子能独立完成。
- 困难胜率：65%-80%，需要开始看技能推荐和属性克制。
- 地狱胜率：45%-65%，更像亲子挑战或熟练后的目标。
- 如果连续失败2次，系统给出温柔提示：“要不要先去简单难度练一下伙伴？”

## 8. 文案与视觉要求

文案：

- 面向7岁孩子，句子短，少抽象词。
- 避免“失败、死亡、惩罚”等强负面词。
- 使用“累了、休息、再挑战、伙伴”等温柔表达。
- 全项目必须修复中文乱码。

视觉：

- 大按钮、大图标、少文字。
- 推荐行动用明显颜色提示。
- 重要结果有庆祝动效。
- 地图、战斗、图鉴都要强化“我的伙伴”的存在感。

## 9. 非目标

以下内容暂不建议加入：

- 复杂装备系统。
- 复杂属性双克制计算展示。
- 交易市场、抽卡、付费、排行榜。
- 高强度PVP平衡。
- 需要大量阅读的长剧情。
- 失败惩罚、资源损耗过重的系统。

## 10. AI执行优先级建议

如果后续交给 AI 继续实现，建议按以下顺序拆任务：

1. 修复中文乱码和核心按钮文案。
2. 首页增加“继续冒险”推荐路径。
3. 战斗技能增加“推荐/普通/小心”提示。
4. 地图增加大陆目标和今日小任务。
5. 增加地图难度配置与默认简单难度。
6. 增加地图难度选择入口和解锁规则。
7. 奖励弹窗重做为儿童友好展示。
8. 创建宝可梦增加性格、喜欢、叫声。
9. 图鉴升级为作品册和冒险日记。
10. 增加亲子旁白模式。

地图难度验收点：

- 新玩家只能稳定进入简单难度，不会误入地狱难度。
- 同一大陆通关简单后，能看到困难入口。
- 同一大陆通关困难后，能看到地狱入口。
- 家长设置可提前解锁高难度。
- 不同难度的敌人等级、Boss强度、宝箱、休息点和奖励确实不同。
- 旧存档进入地图不会报错，默认显示简单难度。

## 11. 成功标准

一次理想游玩流程应是：

1. 孩子打开游戏，点击“继续冒险”。
2. 地图告诉他今天的小目标。
3. 孩子走几格，遇到一个有趣事件。
4. 战斗中系统提示哪个技能更推荐。
5. 孩子胜利或捕获新伙伴。
6. 获得一个看得见的奖励，如贴纸、徽章、升级或新图鉴。
7. 图鉴或日记记录一句属于他自己的冒险故事。

最终体验目标：孩子不只是“玩了一个宝可梦游戏”，而是觉得“我的宝可梦真的活在这个世界里”。
