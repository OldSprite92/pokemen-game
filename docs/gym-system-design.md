# 属性道馆系统策划案

> 创意来源：玩家本人提出。目标是把“找道馆、看规则、临场配队、打赢拿徽章、让伙伴变强”变成每张地图通往 Boss 的核心旅程。

## 1. 定位

目标玩家是有丰富游戏经验的 7 岁孩子，策略深度按 10 岁玩家设计。道馆同时服务三个体验支柱：

1. **探索有目标**：道馆不是装饰，而是挑战地图 Boss 前必须完成的资格挑战。
2. **随机但能读懂**：每次挑战的赛制和对手抽取都有变化；随机带来惊喜，信息和数值保证它不变成坑。
3. **伙伴养成有选择**：徽章先收入徽章盒，孩子决定把哪一枚给哪只同属性伙伴、强化什么能力。

核心循环：

`探索地图 → 找到属性道馆 → 看馆主公布的随机规则 → 选择是否挑战与出战伙伴 → 同时多只对战 → 获得徽章/接受休眠 → 解锁地图 Boss`

## 2. 地图规则与门槛

- 每张地图生成 1 座与地图属性一致的道馆，格子类型为 `gym`。
- 道馆出现在可到达、距离起点至少 3 格的位置；与 Boss 一样随机摆放，不能固定在右上角或任何规律位置。
- 图标为**属性小房子**：🏠 上叠加地图属性的图标与颜色，例如火山地图显示 `🏠🔥`。
- 第一次打败本地图道馆，获得“道馆许可”；Boss 格在此之前显示为锁定状态和清晰提示：“先取得红莲道馆许可”。
- 道馆通过后仍可以复赛；复赛不再影响 Boss 门槛。

## 4. 随机挑战规则

孩子不选择赛制；馆主在挑战卡上公布本次随机规则。孩子只决定：**挑战还是先离开**，以及从自己的非休眠伙伴中派谁出战。这个保留的配队决定是策略的来源。

### 4.1 随机原则

1. 进入道馆后立刻抽取本次规则，并显示在“馆主挑战书”上。
2. 抽取只在当前地图的可用伙伴数范围内进行，不会给只有两只可用伙伴的孩子抽 3v3。
3. 规则和敌方抽取在本次地图中锁定；离开挑战卡不会重掷。挑战成功或失败后，下一次复赛才重新抽取。
4. 敌方从固定的 3–6 人馆内阵容中**无重复随机抽取**，因此馆主确实统领固定队伍，但每次出场顺序/组合有探索感。

| 可用出战伙伴数 | 赛制抽取权重 |
| --- | --- |
| 1 | 1v1：100% |
| 2 | 1v1：40%；2v2：60% |
| 3 或以上 | 1v1：20%；2v2：45%；3v3：35% |

赛制为 2v2 或 3v3 时，再等概率抽取换人规则：**自由换人**或**坚守到底**。1v1 没有替补位，因此自动标为“单骑挑战”。

### 4.2 同时多只对战

2v2 和 3v3 是真正同时上场的队伍战，而不是连续单挑。

| 规则 | 具体行为 |
| --- | --- |
| 回合选择 | 每只仍在场的己方伙伴，各选 1 个技能和 1 个目标；支援技能可指定己方伙伴。 |
| 结算顺序 | 按速度排序；速度相同随机。被击败的伙伴本回合后续行动取消。 |
| 攻击目标 | 单体招式默认点选一只敌人；范围/支援效果在技能卡上明确写出。 |
| 自由换人 | 可把场上一只换为替补；被换下的伙伴本回合不行动，换入伙伴获得 30% 首回合减伤。 |
| 坚守到底 | 禁止主动换人；只有场上伙伴完全战败，才能从替补中补上下一只。 |
| 胜负 | 一方场上和替补均战败则失败；击败对方本局抽中的全部伙伴则胜利。 |

每只伙伴的技能卡必须在多人战时显示“攻击谁”或“帮助谁”，避免孩子不知道该点哪里。默认目标永远是当前生命最低的敌人，但玩家可一键改目标。

## 5. 数值与公平边界

随机的是规则和对手组合，不是数值碾压。敌方等级以玩家实际派出队伍的平均等级为基线；高赛制增加的是战术压力，不是单纯把血量翻倍。

| 赛制 | 敌方等级 | 敌方属性基准 | 目标时长 |
| --- | --- | --- | --- |
| 1v1 | 玩家平均等级 +0 | 1 名馆内伙伴 | 1–2 分钟 |
| 2v2 | +0、+1 | 2 名随机馆内伙伴 | 2–3 分钟 |
| 3v3 | +0、+1、+1 | 3 名随机馆内伙伴 | 3–5 分钟 |

难度地图只增加馆内阵容深度和战术技能比例：简单馆内至少有 1 个明显弱点；困难开始出现状态和守护；地狱才允许组合状态与集火。首次道馆挑战的目标胜率为 65–75%，理解属性与换人后达到 80% 以上。

## 6. 徽章盒与强化

首次通关一座地图道馆，获得 1 枚该地图的**徽章印记**。徽章先进入“徽章盒”，不强制立刻使用；孩子可以在结算页或伙伴页自行分配。

徽章只能给拥有相同属性的伙伴。双属性伙伴可以接受任意一个匹配属性的徽章，例如地面+超能力的“大地法师”可使用地面或超能力道馆徽章。

| 徽章强化 | 数值 | 限制 |
| --- | ---: | --- |
| 体力刻印 | 最大 HP +6 | 每只伙伴最多装 2 枚印记 |
| 攻击刻印 | 攻击 +4 | 同一伙伴不能重复同类刻印 |
| 防御刻印 | 防御 +4 | 同一伙伴不能重复同类刻印 |
| 速度刻印 | 速度 +3 | 同一伙伴不能重复同类刻印 |

徽章的来源和出口闭环：首次通关地图道馆产出 1 枚印记 → 徽章盒储存 → 匹配属性伙伴消耗 1 枚印记获得一次永久强化。复赛只产出经验、贴纸、馆主称号和冒险记录，不再掉落印记，防止无限刷属性。

## 7. 奖励、失败与再次挑战

| 结果 | 内容 |
| --- | --- |
| 首次胜利 | 道馆许可、徽章印记 ×1、经验、馆主合影/故事记录；立即解锁本图 Boss。 |
| 复赛胜利 | 经验、贴纸或馆主称号；有机会发现此前未出战的馆内伙伴信息。 |
| 挑战失败 | 从本局实际派出的伙伴中随机选择 1 只，进入 **10 分钟休眠期**；不能参战，不扣道具、经验、徽章或地图进度。 |
| 挑战书前离开 | 无惩罚；规则保持锁定，回来仍是同一局。 |
| 战斗中撤退 | 视为挑战失败，执行同一休眠规则，避免用撤退刷新不利局面。 |

失败结算要告诉孩子：哪一只伙伴在休息、还剩多久、下次可如何准备；例如“果冻猪在休息 10 分钟。红莲道馆的火焰怕水流，带它回来试试吧。”

## 8. 关键界面流程

1. **地图**：属性小房子图标；Boss 格锁标识与“先完成 XX 道馆”的短句。
2. **道馆门口**：馆主头像、名字、属性、简短招呼；“查看挑战书”与“先去探索”。
3. **挑战书**：大字显示随机得到的“2v2 · 坚守到底”，显示馆内队伍剪影和自己的可用伙伴；只提供“开始挑战”或“暂不挑战”。
4. **队伍准备**：孩子选择与赛制数量相同的伙伴；系统用属性图标提示但不强迫推荐。
5. **多人战斗**：每个己方伙伴下方都有技能和目标按钮；场上有清楚的站位、血条、状态和替补区。
6. **结算**：胜利发徽章并提示 Boss 解锁；失败展示随机休眠伙伴与下次建议。
7. **徽章盒**：按属性排列未使用徽章，点击后只展示符合属性的伙伴及四种强化选择。

## 9. 试玩假设与风险

| 验证内容 | 假设 | 成功标准 |
| --- | --- | --- |
| 随机挑战书 | 不可预知赛制会让孩子先看规则再配队 | 试玩者每 3 次道馆中至少 2 次先读规则再选伙伴。 |
| 同时 2v2/3v3 | 多目标与支援会产生真实战术，而不是只点最高伤害 | 3v3 中，至少 40% 的回合发生了不同目标、支援或换人。 |
| 徽章盒 | “先存后分配”会让玩家主动思考伙伴培养方向 | 至少 60% 玩家不在获得后立即随意使用，而会打开伙伴页比较。 |
| 10 分钟休眠 | 有后果但不没收收藏，能带来复仇而非退出 | 失败后 70% 玩家在伙伴恢复后再次挑战。 |

风险与处理：

- **随机赛制太难**：抽取受可用伙伴数量约束，并以队伍平均等级实时定标。
- **3v3 界面太乱**：固定左右两列站位，目标使用头像点选；默认目标始终可一键确认。
- **攻击强化成为唯一最优**：每只伙伴最多两枚徽章且同项不可重复，速度、防御和体力都有明确用途。
- **10 分钟休眠太挫败**：只影响一只实际出战伙伴，不扣任何长期资源；结算给出具体反制提示。

## 10. 实施顺序

| 阶段 | 最小交付 | 原因 |
| --- | --- | --- |
| G1 | `gym` 格、随机可达放置、馆主/挑战书、首次通过后解锁 Boss | 先验证“道馆是地图目标”是否成立。 |
| G2 | 1v1、固定馆内 3 人阵容、徽章盒与 10 分钟休眠 | 先验证奖励和失败闭环。 |
| G3 | 随机规则、2v2 同时战斗、自由换人 | 验证最核心的随机战术体验。 |
| G4 | 3v3、坚守到底、4–6 人阵容、复赛奖励 | 在界面与多目标操作已被试玩证明后扩展深度。 |

### 实现交接

```yaml
pillars:
  - 地图道馆是 Boss 前的资格挑战
  - 随机规则制造探索，公平定标保证可理解
  - 徽章储存与属性匹配强化带来长期配队选择
core_loop: 探索 -> 发现道馆 -> 阅读随机挑战书 -> 配队 -> 同时队伍战 -> 徽章强化 -> Boss
data_to_add:
  - GymDefinition: mapId, element, gymName, leaderName, rosterSeed, roster, challengeSeed, cleared
  - GymChallenge: format(1|2|3), switchRule(free|locked|solo), opponentIds, playerIds
  - BadgeToken: sourceMapId, element, assignedMonsterId?, statBoost?
acceptance:
  - 每张地图恰有一座随机可达的属性道馆
  - 未通过道馆时 Boss 不可挑战
  - 赛制与馆内出战阵容随机，但不超出玩家可用队伍规模
  - 2v2、3v3 为真正同时上场
  - 首胜徽章可储存，并只可强化同属性伙伴
```
