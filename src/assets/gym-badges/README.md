# Gym badge artwork

The SVG files in this folder are local image assets from [Tabler Icons](https://github.com/tabler/tabler-icons), used under the MIT License. The upstream license is included as `LICENSE.txt`.

They are rendered as local SVG artwork by `GymBadgeEmblem.tsx`; CSS only controls each asset's size, color and placement, never its silhouette.

The seven fusion ingredients intentionally follow the requested visual roles: psychic ring, poison fruit with a top notch, rock polygon, water droplet, grass flower, electric starburst and fire flame.
