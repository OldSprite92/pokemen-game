# Poké Ball artwork

These local PNG item sprites come from the
[PokeAPI sprites repository](https://github.com/PokeAPI/sprites/tree/master/sprites/items).

The in-game mappings are:

- `normal.png`: Poké Ball
- `great.png`: Great Ball
- `ultra.png`: Ultra Ball
- `master.png`: Master Ball
- `legend.png`: Luxury Ball artwork used for the custom Legend Ball
- `transcend.png`: Beast Ball artwork used for the custom Transcend Ball

Pokémon and Pokémon character names are trademarks of Nintendo. The sprites are
stored locally so the shop never depends on a network connection.
